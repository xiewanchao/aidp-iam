按作用对象分开配置：HTTPRoute 级请求策略、HTTPRoute 级后端连接保护，以及 Gateway/listener 级入口 TCP 连接限制。

Route 级 HTTP 策略

作用于当前 HTTPRoute，用于超时、HTTP 请求限流和重试。

Route 级业务后端连接保护

生成 `BackendTrafficPolicy.circuitBreaker`，限制当前路由转发到后端服务时的连接数、等待队列和并发请求数。

Gateway/listener 级入口连接限制

生成 `ClientTrafficPolicy.connectionLimit`，限制客户端进入 Gateway 或指定 listener 的 TCP 连接数，不按单条业务路由区分。
