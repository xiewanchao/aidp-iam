1.1 背景
日常产研协同中，团队经常面临以下三大核心痛点，这些痛点不仅影响效率，更潜藏着巨大的质量与成本风险：

1.产研资产“孤岛化”与“严重脱节”：PRD调整、架构重构或代码修改后，上下游文档往往未能同步更新。这种“代码与文档两张皮”的现象，导致下游联调频频踩坑、测试用例失效，甚至引发线上故障，后期返工成本极高。
2.知识沉淀“碎片化”与“信任危机”：遇到技术难题时，往往依赖口口相传或在各种群聊、旧文档中“大海捞针”。由于答案缺乏溯源标记，开发者不敢直接采信；而直接使用通用大模型又极易产生“幻觉”误导，导致团队对AI工具产生信任危机。
3.团队经验“个人化”与“高频流失”：核心人员流动或转岗后，宝贵的“避坑指南”和隐性经验随之流失。系统缺乏“越用越聪明”的记忆能力，每次新人接手或跨团队协作，都需要老员工重新“口传心授”，新人培养周期长、技能培训成本居高不下。

2、项目介绍
2.1 核心理念：从“副场景问答”走向“主场景业务流融合”
场景定位重塑：传统的“网页对话框问答”仅仅是验证RAG和记忆机制的副场景（探索期、当前形态）。本项目的主场景（成熟期） 是依赖Nexent平台后期提供调用接口，将Agent无缝嵌入到真实的产研作业流中。
业务流融合畅想：未来Agent不应局限于独立的Web界面，而是作为“隐形助手”融入开发链路。例如：
在IDE中通过插件在编码时主动提示架构约束；
在Git Commit或CI/CD流水线中通过Hook自动触发文档一致性校验；
在Code Review阶段自动生成变更影响分析报告。
项目核心价值：从单纯的“提效工具”升级为产研团队的 “数字神经系统”，实现知识在业务流中的自动流转、校验与沉淀，让AI真正成为产研协同的“基础设施”。
2.2 “1+2”多智能体协同与解耦设计
本方案采用 “1+2 多智能体协同” 架构，包含1个主控智能体和2个专家智能体：

Orchestrator Agent（主控调度）：作为唯一入口，负责全局意图识别、用户记忆上下文注入、任务拆解与子Agent调度。
Design Governance Agent（设计治理专家）：专注PRD、架构、API及代码修改的变更解析。通过提取意图、检索昊天知识库进行双向比对（Doc-to-Code & Code-to-Doc），识别不一致项并自动流转DTS工单。
Tech Q&A Agent（技术问答专家）：专注基于RAG与历史记忆的精准答疑，严格执行引用校验，确保答案100%附带 [doc_id:xxx] 溯源标记。
2.3 多智能体在编码过程中的引入与解耦融入
知识库、智能体引入编码：在开发者编写代码时，Tech Q&A Agent可作为IDE侧边栏助手，根据当前光标所在的代码上下文，主动推送相关的架构设计约束、历史踩坑记录或相似模块的实现参考，实现“知识找人”。
流程解耦与心流保护：在编码过程中，开发者最忌讳被打断。因此我们将流程异步解耦：开发者只需专注写代码，当代码提交（Push/MR）时，Design Governance Agent在后台异步接管，自动进行代码与文档的比对校验。若发现脱节，自动生成修改建议或DTS草稿单，既保证了文档一致性，又完全不打断开发者的编码心流。
2.4 融入开发场景与SOP作业流
全链路开发场景融入：

需求评审期：Design Agent辅助对比历史相似需求，提示潜在的设计遗漏。
编码与CR期：如上所述，Q&A Agent提供实时上下文，Design Agent在CR阶段提供“代码-文档”一致性审查报告。
SOP（标准作业程序）流的融入：
什么时候用：当触发特定SOP节点时自动介入。例如“新人接手核心模块SOP”、“发版前配置检查SOP”、“故障复盘SOP”。
效果如何：将过去挂在Wiki上无人问津的“死SOP”转化为Agent的“活指令”。Agent会根据SOP节点自动拉取相关文档、检查前置条件、生成Checklist。效果上，实现了从“人找SOP”到“Agent执行SOP并引导人”的转变，大幅降低人为遗漏风险，确保流程合规率提升至近100%。

3、业务收益
3.1 效率提升与核心价值
本智能体精准狙击“产研文档脱节”与“知识流失”的核心痛点，带来显著的效率提升：

痛点精准：直击日常产研协同中手工核对文档、跨系统搬运建单、手动整理Wiki等繁琐事务。
价值体现：
核对耗时骤降：支持代码修改反向追溯与文档比对，单次核对耗时从 40分钟缩短至 30秒。
人力工时节省：通过 /card 一键沉淀经验及自动创建DTS草稿单，省去手动整理和流转的时间，预计月度可节省 ≥30 人天。
准确率与信任度提升：强制引用校验杜绝AI幻觉，技术答疑准确率和可信度大幅提升，让团队“敢用、爱用”。
3.2 公司级使用场景：赋能人工技能培训与新人Onboarding
除了日常产研协同，本项目在公司人工技能培训场景中具有巨大的延展价值：

个性化“带教导师”：利用Agent的长期记忆和知识库，可为新人或转岗员工打造专属的“带教Agent”。Agent能记录新人的提问习惯和知识盲区，动态调整培训策略。
隐性经验显性化培训：将老员工通过 /card 沉淀的“避坑指南”和“最佳实践”转化为培训教材。当新人遇到类似问题时，Agent不仅给出答案，还会以“导师”口吻补充历史背景和业务思考，加速新人从“知道怎么做”到“理解为什么这么做”的认知跃迁，大幅缩短Onboarding周期。
3.2 交互设计与体验
易用性：采用纯自然语言交互，用户只需粘贴一段变更描述或直接提问，无需编写代码或学习复杂指令，非技术人员（如产品经理）也能快速上手。
交付体验：通过skill限制输出成果高度结构化。治理流直出“结构化一致性报告”并自动建单；问答流输出带 [doc_id:xxx] 溯源标记的专业解答；/card 指令直出标准Markdown知识卡片。记忆系统的引入让Agent具备跨会话继承上下文的能力，带来“懂你”的拟人化交互体验。
3.3 关键创新
架构创新：创新采用“1+2 多智能体协同 + 纯文件双轨制记忆”架构。多智能体确保复杂意图精准拆解；双轨制记忆（长期精华+短期日记）彻底告别“每次都要重新教AI”，让Agent具备强大的知识蒸馏与跨会话检索能力。
极简MCP设计：自研极简 Memory MCP 填补了平台在轻量级记忆管理上的空白。彻底零数据库依赖，底层直接基于本地文件系统读写Markdown，具备极强的白盒可解释性和低成本复制潜力。
推广潜力：
该Agent模式不依赖重型基础设施，只要设计文档管理维护的团队都可以开箱即用。
自研MCP“即插即用”，可极低成本复制到其他业务部门（如测试、运维团队），快速构建团队专属的“记忆日记”。
AI辅助：该项目的相关所有skill、mcp-memory均由AI开发（包括队伍/项目头像），真正践行了“用AI开发AI”的极客理念。
