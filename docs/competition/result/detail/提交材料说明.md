## 主线叙事

一句话定位：

> 基于 AIDP IAM / Gateway 复杂工程，实践一套 AI 友好型软件工程方法：先把需求、上下文、测试和工程约束变成 AI 可理解、可验证、可继承的资产，再由 AI 协同完成代码、测试、部署、修复和运维闭环，并将该流程从蓝区实验复制到黄区 IT 助手、产研助手和运维助手。

主推创新点：

1. AI 友好型软件工程。
2. 测试即规约 + TDD。
3. 上下文工程 + 长短期记忆。
4. 白+黑协作验收。
5. 蓝区到黄区迁移。
6. 自动运维与根因分析闭环。
