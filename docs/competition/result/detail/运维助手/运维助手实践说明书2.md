# Morphis 面板设计文档

## 1 需求概述

Morphis 面板是面向DTFS客户端运维工程师的智能辅助工作台，旨在将 FC 流控诊断、一键组网部署、IO 模型分析、环境信息抓取、CVE 漏洞周推五大高频运维场景从"人工 SSH + 经验判断"模式升级为"一键触发 + AI 推理"模式。

核心需求：

- 提供统一的 Web 工作台，集成 5 大业务模块 + 效能看板 + 兼容性矩阵 + 开发者数据 + AI 对话
- 支持多主机并发 SSH 连接，自动化数据采集
- 集成 LLM 推理能力，对采集数据进行专业解读与建议生成
- 通过 SSE 实时推送 AI 推理过程，提升交互体验
- 支持定时任务调度（CVE 周推）与多通道消息推送（小鲁班 + Outlook 邮件）

## 2 功能设计

### 2.1 核心功能

#### F1 流控诊断

- **输入**：多主机 SSH 配置（IP、端口、用户名、密码、备注、网口列表）
- **处理**：SSH 远程执行 FC 流控采集命令，LLM 分析流控指标并生成诊断结论
- **输出**：各主机各网口的诊断结果（状态、利用率、错误计数等），异常状态高亮标识
- **交互**：Accordion 手风琴展开各主机诊断详情

## 5 核心算法

### 5.1 SSH 远程命令执行与异常分级

```python
# 核心流程：连接 → 执行 → 采集 → 分级异常
def execute_command(host, command, username, password, port, timeout):
    client = paramiko.SSHClient()
    client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    try:
        client.connect(hostname=host, port=port, ...)
        stdin, stdout, stderr = client.exec_command(command, timeout=timeout)
        exit_code = stdout.channel.recv_exit_status()
        return SSHResult(host, command, exit_code, stdout, stderr)
    except paramiko.AuthenticationException:
        raise SSHAuthError(host=host)          # code=1002
    except (paramiko.SSHException, OSError):
        raise HostUnreachableError(host=host)   # code=1001
    finally:
        client.close()
```

异常分级设计确保不同故障类型有明确的错误码和用户提示，避免模糊的"连接失败"。

### 5.2 LLM 推理与 Prompt 工程

```python
# 分层 Prompt 架构
SYSTEM_PROMPT = """
你是 Morphis AI，一位资深的分布式NAS并行客户端运维专家。
你精通 FC 交换机、存储组网、IO 性能分析、CVE 安全漏洞、Linux内核等专业领域。
回答要求条理清晰，使用 Markdown 格式，多用步骤引导。
如果用户的问题超出你的专业范围，请诚实说明。
"""

def chat_completion(system_prompt, user_message, temperature=0.2):
    client = get_llm_client()  # OpenAI 单例
    response = client.chat.completions.create(
        model=settings.openai_model,
        messages=[
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_message},
        ],
        temperature=temperature,  # 低温度保证推理稳定性
        max_tokens=4096,
    )
    return response.choices[0].message.content
```

### 5.3 SSE 流式推送与前端状态机

后端以 `StreamingResponse` 逐 chunk 输出 LLM 推理结果：

```python
async def _stream_openai(messages):
    async for chunk in await client.chat.completions.create(
        model=settings.openai_model, messages=messages, stream=True
    ):
        delta = chunk.choices[0].delta
        if delta and delta.content:
            yield f"data: {json.dumps({'content': delta.content})}\n\n"
    yield "data: [DONE]\n\n"
```

前端 `useSSE` Hook 管理状态机流转：

```
idle → connecting → streaming → done
                   ↘ error
```

- 组件卸载自动 `abort()` 连接
- 收到 `[DONE]` 将 `streamingRef` 内容固化为 `messages` 历史条目
- 收到 `error` 字段直接展示错误提示，不进入重连
