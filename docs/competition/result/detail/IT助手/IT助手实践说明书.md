# IT-Assistant-Web 项目说明

## 1. 项目概述

### 1.1 项目背景

当前黄区补充UT代码费时费力，很多都是重复性的工作。开发人员使用AI在本地生成UT之后还需要上传到环境上跑覆盖率，自动化程度低，浪费时间。

### 1.2 项目目标

实现一款能够让AI半自动进行迭代提升覆盖率的工具，能够自己跑UT用例，查看覆盖率情况，自己完善问题。

### 1.3 核心价值

| 价值维度 | 具体描述 |
|---------|---------|
| **效率提升** | 覆盖率人工补充到76%需要6小时，交给AI后1个小时即可完成 |
| **质量提升** | 存量代码覆盖率从4%提升到76%，增强了存量代码的覆盖密度 |
| **交互优化** | 通过环境配置传递上下文，让AI工具感知环境信息，实时交互提升开发效率 |
| **自动化程度** | 规范补充后，AI可自动进行覆盖率补充、迭代、问题识别 |

---

## 2. 关键创新点

### 2.1 环境感知机制

通过环境配置，将上下文传递给CodeAgent，让AI工具可以感知到环境信息：
- 服务器IP、端口、用户名、工作目录等环境变量自动传递
- 项目路径信息实时同步
- 环境配置持久化存储在 `envs.json` 中

### 2.2 Web内嵌终端交互

在网页内嵌CodeAgent工具，实时进行交互：
- WebSocket实时终端，支持命令输入输出
- 无需切换窗口，在浏览器内完成与AI的交互
- 支持多环境管理和快速切换

### 2.3 Spec Driven Develop 实践

鼓励先编写结构化的Spec（规约），由AI根据Spec生成代码：
- AI自动进行覆盖率补充、迭代
- 通过skills规范约束AI行为，降低犯错频率
- 生成符合团队编码规范的代码，可通过静态扫描

### 2.4 可演进Skills体系

通过生成补充UT skills，形成可复用的规范模版：
- AI犯错的频率逐渐降低
- 可生成更加通用的skills规范
- 相同模版的UT补充效率持续提升

### 3.4 API设计

| 方法 | 路径 | 说明 | 请求体 | 响应 |
|------|------|------|--------|------|
| GET | `/` | 获取前端页面 | - | HTML页面 |
| POST | `/api/connect` | 连接CodeAgent CLI | 环境配置对象 | `{success, message}` |
| POST | `/api/disconnect` | 断开CodeAgent连接 | - | `{success, message}` |
| POST | `/api/test-connection` | 测试SSH连接 | `{ip, port, username, password, workdir}` | `{success, message, envInfo}` |
| GET | `/api/env-list` | 获取环境列表 | - | `{success, envs: [...]}` |
| POST | `/api/env-list` | 保存环境列表 | 环境数组`[...]` | `{success, message}` |
| POST | `/api/save-env` | 保存当前环境 | 环境对象 | `{success, message}` |
| GET | `/api/get-current-env` | 获取当前环境 | - | `{success, env}` |
| GET | `/api/status` | 获取连接状态 | - | `{connected, running, env}` |

### 3.5 环境配置对象

```json
{
  "name": "环境名称",
  "ip": "服务器IP",

  "username": "用户名",
```

| LLT_ENV_USER | 用户名 |
| LLT_ENV_WORKDIR | 工作目录 |
| LLT_ENV_PROJECT_PATH | 项目路径 |

## 4. 使用说明

### 4.1 快速开始

```bash
# 安装依赖
npm install

# 启动服务
cd server
node server.js

# 服务启动后访问: http://localhost:3002
```

### 4.2 操作流程

1. **添加环境** - 在环境管理表单中填写服务器信息，点击"添加环境"
2. **测试连接** - 点击"测试连接"验证SSH连接是否正常
3. **连接CodeAgent** - 从下拉框选择环境，点击"连接CodeAgent"
4. **终端交互** - 在终端中输入命令与CodeAgent进行交互

## 5. 问题记录与思考

### 5.1 关键问题解决

- **环境变量感知问题**：在制作网站CodeAgent过程中，将已有的环境信息传给CodeAgent，当在界面登录之后，发现CodeAgent并不能感知到环境变量。AI并不认为有问题，一直在"原地打转"。通过提示"这种方法已经修改完了，但是还是未生效，这个方法是否有效，是否尝试一下其它方法"，AI换了思路后立马发现了问题。

- **UT补充迭代问题**：AI补充完用例之后，首次补充会遇到很多问题，出现很多bug。虽然靠自己迭代最后也能解决，但中间踩了不少"坑"。让AI自己总结了这些"坑"，再让它生成一次，效率比之前提升了不少。

### 5.2 个人思考

- AI应用过程中，并不能一蹴而就，需要开发者不断去进行提示
- 制定规范和约束，让AI能够少犯错误，进而提升效率
- AI在解决重复问题场景很占优势，像UI界面、UT补充这些工作可以通过AI节省人力
- 通过skills规范，可以迅速提升AI的效率
