# AIDP IAM 用户使用说明书

## 1. 文档说明

本文档面向使用 AIDP IAM 的普通管理员和业务管理员，说明如何通过界面完成登录、Token 获取、SAML 身份提供商配置、用户与用户组管理，以及用户组权限配置。

截图请按实际材料替换到本文中的图片占位位置。

## 2. 用户登录与 Token 获取

### 2.1 功能说明

用户通过 AIDP 登录界面完成身份认证。登录成功后，服务端会签发访问令牌，前端页面后续访问管理接口时会自动携带该令牌。

需要注意：

- Token 由服务端签发，Token 的签发时间和过期时间以服务端时间为准。
- 如果客户端时间、服务端时间或存储设备时间差异较大，可能出现刚获取的 Token 被判断为已过期或尚未生效的情况。
- 发生上述问题时，需要先通过 DeviceManager 同步设备时间，再重新登录获取 Token。
- 普通界面操作不需要手工复制 Token；只有接口联调、问题定位或自动化测试时才需要查看或获取 Token。

![用户登录界面](./images/iam-user-login.png)

![DeviceManager 时间同步界面](./images/devicemanager-time-sync.png)

### 2.2 操作步骤：用户登录

1. 打开 AIDP 访问地址，进入用户登录界面。
2. 在登录页面输入用户名和密码。
3. 单击“登录”。
4. 登录成功后，系统进入 AIDP 管理界面。
5. 如果登录失败，根据页面提示检查用户名、密码、用户状态和网络连接。

### 2.3 操作步骤：获取 Token

1. 完成用户登录。
2. 打开浏览器开发者工具。
3. 进入存储信息页面，查看当前站点保存的认证信息。
4. 查找 `access_token`、`refresh_token` 或等价认证字段。
5. 复制需要联调使用的 Token。
6. 在接口联调工具中使用如下请求头携带 Token：

```text
Authorization: Bearer <access_token>
```

### 2.4 操作步骤：同步设备时间

1. 登录 DeviceManager 界面。
2. 选择“系统 > 时间设置”。
3. 查看当前设备时间、时区和 NTP 配置。
4. 根据现场要求选择手动同步或 NTP 自动同步。
5. 单击“保存”或“同步”。
6. 时间同步完成后，重新登录 AIDP 并重新获取 Token。

## 3. 配置 IdP SAML 登录

### 3.1 功能说明

SAML IdP 配置用于接入外部身份提供商。配置完成后，用户可以通过外部身份提供商完成认证，再回到 AIDP 使用系统功能。

SAML 配置通常包括：

- 单点登录地址：外部 IdP 的 SSO 登录地址。
- 单点登出地址：外部 IdP 的 SLO 登出地址，按现场 IdP 能力配置。
- Entity ID：外部 IdP 或服务提供方标识。
- 签名证书：用于校验 SAML 断言或登出请求签名。
- NameID 格式：用于指定用户身份标识格式。

![SAML IdP 配置界面](./images/iam-saml-idp-config.png)

### 3.2 Attribute Mapper 说明

Attribute Mapper 用于把 SAML 断言中的属性映射为 AIDP/Keycloak 用户属性。

常见映射关系如下：

| SAML 属性 | 本地用户属性 | 说明 |
|---|---|---|
| `username` 或 `uid` | `username` | 用户登录名或唯一标识 |
| `email` | `email` | 用户邮箱 |
| `firstName` | `firstName` | 名 |
| `lastName` | `lastName` | 姓 |

配置 Attribute Mapper 后，用户首次通过 SAML 登录时，系统会根据映射结果创建或更新用户信息。

### 3.3 Group Mapper 说明

Group Mapper 用于根据 SAML 断言中的属性或组信息，把用户自动加入指定用户组。

常见使用方式：

- 根据部门属性加入部门组。
- 根据岗位属性加入管理员组或普通用户组。
- 根据外部 IdP 返回的 group 属性同步用户组。

配置时需要关注：

- 属性名必须与 SAML 断言中返回的属性一致。
- 匹配值需要与外部 IdP 返回值一致。
- 用户组路径建议使用完整路径，例如 `/tenant-admins`。
- 修改 Group Mapper 后，通常需要用户重新登录后才能看到最新组关系。

### 3.4 操作步骤：配置 SAML IdP

1. 登录 AIDP 管理界面。
2. 选择“身份管理 > 身份提供商”。
3. 单击“新建”或“导入 SAML 元数据”。
4. 如果选择导入元数据，单击“请选择文件”，选择外部 IdP 提供的 metadata 文件。
5. 如果选择手动配置，填写 SSO 地址、SLO 地址、Entity ID、NameID 格式和签名证书。
6. 配置完成后，单击“保存”。
7. 返回身份提供商列表，确认 SAML IdP 状态为启用。

### 3.5 操作步骤：配置 Attribute Mapper

1. 在身份提供商列表中选择目标 SAML IdP。
2. 进入“属性映射”页面。
3. 单击“新建 Mapper”。
4. 填写 Mapper 名称。
5. 填写 SAML 属性名。
6. 选择或填写本地用户属性。
7. 单击“保存”。
8. 使用外部 IdP 用户登录，检查本地用户属性是否正确同步。

### 3.6 操作步骤：配置 Group Mapper

1. 在身份提供商列表中选择目标 SAML IdP。
2. 进入“用户组映射”页面。
3. 单击“新建 Group Mapper”。
4. 填写 Mapper 名称。
5. 填写匹配的 SAML 属性名和属性值。
6. 选择需要自动加入的用户组。
7. 单击“保存”。
8. 使用满足条件的外部 IdP 用户重新登录。
9. 在用户详情中确认用户已加入目标用户组。

## 4. 用户管理

### 4.1 功能说明

用户管理用于维护 AIDP 本地用户，包括创建用户、编辑用户信息、启用或禁用用户、重置密码、删除用户，以及查看用户所属用户组。

![用户管理界面](./images/iam-user-management.png)

### 4.2 操作步骤：创建用户

1. 登录 AIDP 管理界面。
2. 选择“身份管理 > 用户管理”。
3. 单击“新建用户”。
4. 填写用户名、昵称、邮箱等基础信息。
5. 设置用户初始密码。
6. 根据需要选择是否启用用户。
7. 单击“保存”。
8. 在用户列表中确认新用户已创建成功。

### 4.3 操作步骤：编辑用户

1. 登录 AIDP 管理界面。
2. 选择“身份管理 > 用户管理”。
3. 在用户列表中找到目标用户。
4. 单击目标用户对应的“编辑”。
5. 修改用户昵称、邮箱、状态或其他允许编辑的字段。
6. 单击“保存”。
7. 返回用户列表，确认用户信息已更新。

### 4.4 操作步骤：重置用户密码

1. 登录 AIDP 管理界面。
2. 选择“身份管理 > 用户管理”。
3. 在用户列表中找到目标用户。
4. 单击“重置密码”。
5. 输入新密码并确认。
6. 单击“确定”。
7. 通知用户使用新密码重新登录。

## 5. 用户组管理

### 5.1 功能说明

用户组用于对用户进行分类管理。管理员可以创建用户组、编辑用户组、删除用户组，以及维护用户组成员。

![用户组管理界面](./images/iam-group-management.png)

### 5.2 操作步骤：创建用户组

1. 登录 AIDP 管理界面。
2. 选择“身份管理 > 用户组管理”。
3. 单击“新建用户组”。
4. 填写用户组名称和描述。
5. 单击“保存”。
6. 在用户组列表中确认用户组已创建成功。

### 5.3 操作步骤：维护用户组成员

1. 登录 AIDP 管理界面。
2. 选择“身份管理 > 用户组管理”。
3. 在用户组列表中选择目标用户组。
4. 进入用户组详情页面。
5. 单击“添加成员”。
6. 选择需要加入该用户组的用户。
7. 单击“确定”。
8. 在成员列表中确认用户已加入用户组。

## 6. 用户组权限配置

### 6.1 功能说明

用户组权限配置用于给用户组分配资源访问权限。权限生效后，用户组内的成员会继承该用户组的权限。

常见权限角色包括：

| 角色 | 说明 |
|---|---|
| Owner | 拥有资源的管理权限，可进行查看、修改、删除等操作 |
| Contributor | 拥有资源的使用和编辑权限，通常不能进行高风险管理操作 |
| Viewer | 仅拥有资源查看权限 |

权限配置通常由以下信息组成：

- 应用或资源对象。
- 用户组。
- 权限角色。
- 可访问的方法或操作。

![用户组权限配置界面](./images/iam-group-permission-config.png)

### 6.2 操作步骤：配置用户组权限

1. 登录 AIDP 管理界面。
2. 选择“权限管理 > 用户组权限配置”。
3. 选择需要配置权限的应用或资源对象。
4. 选择目标用户组。
5. 选择权限角色，例如 Owner、Contributor 或 Viewer。
6. 根据需要勾选允许访问的方法或操作。
7. 单击“保存”。
8. 使用该用户组内的用户登录系统。
9. 访问对应资源，确认权限配置已生效。

### 6.3 操作步骤：修改用户组权限

1. 登录 AIDP 管理界面。
2. 选择“权限管理 > 用户组权限配置”。
3. 查找目标应用、资源对象和用户组。
4. 单击“编辑”。
5. 调整权限角色或允许访问的方法。
6. 单击“保存”。
7. 重新访问对应资源，确认权限变更已生效。

### 6.4 操作步骤：删除用户组权限

1. 登录 AIDP 管理界面。
2. 选择“权限管理 > 用户组权限配置”。
3. 查找目标应用、资源对象和用户组。
4. 单击“删除”或“移除权限”。
5. 系统弹出确认对话框。
6. 单击“确定”。
7. 使用该用户组内的用户重新访问对应资源，确认权限已被收回。

## 7. 常见问题

### 7.1 登录后提示 Token 过期

可能原因是服务端时间和客户端时间不一致。请先在 DeviceManager 中同步设备时间，然后重新登录。

### 7.2 SAML 登录后用户没有自动加入用户组

请检查 Group Mapper 的属性名、属性值和用户组路径是否与外部 IdP 返回的 SAML 断言一致。修改后需要用户重新登录。

### 7.3 用户无法访问已授权资源

请检查用户是否属于目标用户组，以及用户组是否已经配置对应资源权限。权限修改后建议用户重新登录或刷新页面。
