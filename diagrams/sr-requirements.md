【IAM】支持用户认证、应用注册与外部 IdP 接入

1. 简要说明

基于 Keycloak 的 groups 模型实现用户认证体系，支持本地密码登录和外部 IdP（SAML/OIDC）联邦登录。用户登录后获取带 groups 信息的 JWT。支持通过 License 注册和管理可用应用，配置外部企业 IdP 实现 SSO。

2. Actor

管理员：管理用户/组、注册应用、配置外部 IdP
普通用户：通过本地或 SSO 方式登录系统
外部 IdP 用户：首次联邦登录时自动创建账号
系统：部署时自动初始化基础身份数据

3. 前置条件

数据库和 Keycloak 已部署并可访问
Keycloak Admin API 可用

4. 最小保证

用户登录失败不会破坏已有数据
外部 IdP 配置错误不影响本地登录

5. 成功保证

1）用户登录后 JWT 包含 groups 字段
2）注册应用时自动创建对应管理员组
3）License 开关即时生效
4）外部 IdP 用户首次登录后自动创建本地账号并加入默认用户组
5）JWT 包含正确的 groups 信息

6. 触发事件

1）普通用户：发起本地登录或外部 IdP SSO 登录
2）管理员：注册应用或更新 License 信息
3）管理员：配置外部 IdP
4）系统：首次部署触发身份数据初始化

7. 主成功场景

用户认证：
1）普通用户在登录页输入用户名和密码，系统验证凭证成功后签发包含 groups 的 JWT，用户获得访问令牌可以访问业务系统
2）普通用户的 JWT 即将过期时，前端自动使用 Refresh Token 请求新令牌，系统验证有效后签发新 JWT，用户会话不中断
3）普通用户使用无效凭证登录，系统返回认证失败提示，不泄露具体失败原因

应用注册：
1）管理员调用应用注册接口，填写应用名称和路径前缀，系统创建应用记录并自动生成对应的管理员组和默认资源规则，管理员收到创建成功确认
2）管理员调用应用更新接口将 License 设为停用，系统立即使该应用下所有路径的请求被拒绝，管理员收到更新成功确认
3）管理员调用应用更新接口将 License 恢复启用，系统立即恢复该应用下所有路径的正常访问，管理员收到更新成功确认

外部 IdP 接入：
1）管理员上传企业 IdP 的 SAML Metadata 文件，系统解析并自动创建 IdP 实例和默认属性映射规则，管理员收到配置成功确认
2）企业员工点击"企业登录"按钮，系统跳转至企业 IdP 完成身份验证，验证通过后自动创建本地影子账号并加入默认用户组，员工获得 JWT 令牌成功进入系统
3）管理员删除某个外部 IdP 实例，该 IdP 的 SSO 登录入口立即失效，已创建的影子用户保留但无法再通过该 IdP 登录

8. 扩展场景（包括异常场景）

•       拒绝场景：凭证无效返回认证失败、JWT 过期返回 401、Keycloak 不可用时新用户无法登录
•       约束：N/A
•       规格：N/A
•       升级：支持滚动升级，不覆盖已有数据
•       可靠性：≥2 副本，单实例故障已登录用户不受影响
•       性能：N/A
•       安全：JWT 使用 RS256 签名，密码使用 PBKDF2 存储
•       韧性：Keycloak 宕机时已登录用户不受影响（JWKS 缓存），新用户无法登录，恢复后自动接受新登录
•       可服务：Keycloak 恢复后自动接受新登录请求
•       可测试：N/A

【Gateway】支持路径级鉴权与资源访问鉴权

1. 简要说明

请求经过 Gateway 时实现两级鉴权：第一级路径级鉴权，检查应用是否启用、路径是否受保护、用户是否在允许的组中；第二级资源实例级鉴权，检查用户对具体资源的访问权限，支持子资源继承和权限-操作映射。

2. Actor

普通用户：发起业务请求，触发鉴权
管理员：配置路径保护规则
系统：执行 JWT 验证、路径级策略计算、资源权限检查

3. 前置条件

用户请求携带有效 JWT
路径规则和资源权限数据已就绪

4. 最小保证

鉴权失败返回 403，不泄露内部信息
策略引擎故障时默认拒绝，不会误放行

5. 成功保证

1）所有请求经过路径级鉴权
2）应用禁用时该应用下所有请求被拒绝
3）受保护路径无对应组的用户被拒绝
4）有资源权限的用户放行，无权限的用户被拒绝
5）权限不足（如 viewer 尝试删除）时被拒绝
6）子资源操作检查父资源权限

6. 触发事件

1）普通用户：发起任意 HTTP 请求到达 Gateway
2）管理员：创建、修改或删除路径保护规则

7. 主成功场景

路径级鉴权：
1）普通用户请求访问受保护的业务路径，系统检查用户所属组与路径规则匹配，用户在允许的组中，请求被放行到达后端应用
2）普通用户请求访问受保护的业务路径，系统检查用户所属组与路径规则不匹配，系统返回 403 拒绝访问
3）普通用户请求访问未配置保护规则的业务路径，系统确认该用户属于默认用户组且路径非管理路径，请求被放行
4）普通用户请求访问已停用应用的路径，无论用户属于何种组，系统直接返回 403 拒绝访问
5）管理员调用路径规则管理接口创建新的保护规则，指定路径前缀和允许访问的组，系统在规则刷新周期内生效，管理员收到创建成功确认
6）管理员调用路径规则管理接口删除已有保护规则，系统在规则刷新周期内移除该规则，对应路径恢复为默认访问策略

资源级鉴权：
1）普通用户请求读取某个具体资源（GET），系统检查该用户对该资源拥有 viewer 及以上权限，请求被放行
2）普通用户请求修改某个具体资源（PUT/PATCH），系统检查该用户对该资源拥有 contributor 及以上权限，请求被放行
3）普通用户请求删除某个具体资源（DELETE），系统检查该用户对该资源拥有 owner 权限，请求被放行
4）普通用户请求访问某个资源的子资源，该子资源无独立权限记录，系统自动检查父资源的权限并继承，权限足够则放行
5）普通用户请求访问某个资源但无任何权限记录，系统返回 403 拒绝访问
6）管理员请求访问任意资源，系统识别管理员身份后跳过资源级鉴权，请求被放行

8. 扩展场景（包括异常场景）

•       拒绝场景：JWT 无效或过期返回 401、无路径权限返回 403、无资源权限返回 403、权限不足返回 403
•       约束：N/A
•       规格：N/A
•       升级：支持滚动升级，多副本部署，逐个重启不中断鉴权
•       可靠性：≥2 副本，单实例故障不影响鉴权
•       性能：N/A
•       安全：未授权请求不会到达后端应用、策略引擎故障默认拒绝
•       韧性：策略引擎恢复后自动接受查询
•       可服务：策略引擎恢复后自动接受查询
•       可测试：N/A
•       支持的产品：A800

【Gateway】支持资源 ACL 自动同步与权限管理

1. 简要说明

在 Gateway 响应阶段自动拦截资源创建和删除响应，实现 ACL 自动同步；提供 ACL 管理 API 支持资源分享、取消分享和权限修改；通过重试队列保障 ACL 数据最终一致性。

2. Actor

普通用户：创建/删除资源时触发 ACL 自动同步
资源 owner：通过 ACL API 分享、修改或撤销资源权限
系统：Gateway 响应阶段自动写入/清理 ACL、后台定时重试失败记录

3. 前置条件

资源数据存在
Gateway 策略已绑定
能验证 owner 权限，用于 ACL API 鉴权

4. 最小保证

ACL 写入失败时记录到重试队列，不丢失
资源管理组件故障不阻塞业务请求（failOpen）
ACL API 操作失败不影响已有权限数据

5. 成功保证

1）创建资源后自动写入 owner 权限记录
2）删除资源后该资源的所有权限记录被清除
3）分享后目标用户/组可按对应权限级别访问资源
4）修改权限后立即生效
5）撤销分享后目标用户无法访问该资源
6）写入失败时重试队列有记录，后台重试最终成功
7）所有重试记录最终被处理（成功写入或达到最大重试次数）

6. 触发事件

1）普通用户：创建资源（系统收到创建成功响应）
2）普通用户：删除资源（系统收到删除成功响应）
3）资源 owner：调用 ACL API 分享/修改/撤销权限
4）系统：定时任务触发重试

7. 主成功场景

ACL 自动同步（创建）：
1）普通用户通过业务应用创建一个新资源，业务后端返回创建成功，系统自动为该用户写入一条 owner 权限记录，用户自动成为该资源的所有者
2）普通用户通过业务应用创建资源，业务后端返回非创建成功状态码（如 400 或 200），系统不触发 ACL 写入，不产生任何权限记录

ACL 自动同步（删除）：
1）普通用户通过业务应用删除一个已有资源，业务后端返回删除成功，系统自动清除该资源的所有权限记录（包括 owner 和所有被分享者的记录），释放相关权限

权限分享与管理：
1）资源 owner 调用分享接口，指定目标用户和权限级别（viewer/contributor/owner），系统创建权限记录，被分享用户立即可按对应权限级别访问该资源
2）资源 owner 调用分享接口，指定目标用户组和权限级别，系统创建权限记录，该组所有成员立即可按对应权限级别访问该资源
3）资源 owner 调用权限查询接口，系统返回该资源的所有权限条目列表，包含每个被分享者的身份和权限级别
4）资源 owner 调用权限修改接口，将某用户的权限从 viewer 提升为 contributor，系统更新权限记录，该用户立即获得修改资源的能力
5）资源 owner 调用取消分享接口，系统删除对应权限记录，被撤销用户立即无法访问该资源
6）非 owner 用户调用分享/修改/撤销接口，系统返回 403 拒绝操作

可靠性重试：
1）系统自动同步 ACL 时遇到数据库故障，写入失败的操作被记录到重试队列，业务请求不受影响（failOpen），系统后台按指数退避策略自动重试
2）数据库恢复后，系统后台取出重试队列中待处理的记录逐条重新执行，执行成功后从队列中移除
3）某条记录经过最大重试次数后仍然失败，系统停止重试并保留该记录供人工排查

8. 扩展场景（包括异常场景）

•       拒绝场景：非 owner 调用 ACL API 返回 403、资源不存在返回 404、重复分享返回 409
•       约束：资源管理组件包含 ACL API 和 ACL 自动同步两个服务端口
•       规格：重试间隔 5 秒起，指数退避至约 42 分钟，最大重试 10 次
•       升级：支持滚动升级，多副本部署逐个重启，failOpen 保证升级期间业务请求不中断
•       可靠性：≥2 副本
•       性能：重试吞吐每 5 秒一批，逐条处理
•       安全：ACL API 鉴权只有 owner 可分享/修改/撤销；failOpen 模式下业务可用但权限延迟生效，非安全降级
•       韧性：ACL 延迟同步时超时放行响应，ACL 后台补写
•       可服务：恢复后自动处理重试队列，可通过重试队列查看未处理的 ACL 操作
•       可测试：N/A
•       支持的产品：A800

【Gateway】支持资源列表过滤

1. 简要说明

在请求阶段感知分页参数，查询用户可访问的资源列表，按分页取出当前页对应的资源 ID 注入请求头，后端应用读取请求头查询业务数据并返回分页结果。实现用户只能看到自己有权限的资源。

2. Actor

普通用户：发起资源列表查询请求
系统：请求阶段查询权限数据，注入可访问资源 ID 列表
后端应用：读取注入的请求头，查询业务数据返回分页结果

3. 前置条件

资源权限数据已存在
Gateway 策略已绑定

4. 最小保证

列表过滤处理失败时 failOpen 放行，后端收不到过滤信息返回空列表
不会返回用户无权限的资源

5. 成功保证

1）列表结果只包含用户有权限的资源
2）分页准确，总数和当前页数据一致
3）每次注入的 ID 数量等于分页大小，不会超限

6. 触发事件

1）普通用户：发起 GET 请求访问资源集合路径

7. 主成功场景

列表过滤：
1）普通用户请求浏览资源列表（第 1 页），系统查询该用户可访问的资源 ID 列表和总数，将当前页对应的 ID 和总数注入请求头，后端应用读取请求头返回过滤后的资源列表和分页信息，用户看到的列表只包含自己有权限的资源
2）普通用户翻页请求第 N 页，系统按分页偏移取出对应的 ID 切片注入请求头，后端返回正确的第 N 页数据
3）普通用户请求列表但无任何可访问资源，系统注入空 ID 列表和总数 0，后端返回空列表
4）管理员请求资源列表，系统识别管理员身份后不注入过滤信息，后端返回全量数据

8. 扩展场景（包括异常场景）

•       拒绝场景：N/A（failOpen，不拒绝请求）
•       约束：N/A
•       规格：分页默认 page=1, size=20，size 上限 100
•       升级：支持滚动升级，failOpen 保证升级期间列表返回空而非报错
•       可靠性：资源管理组件宕机时 failOpen，列表返回空，单资源访问不受影响
•       性能：N/A
•       安全：不会返回用户无权限的资源 ID
•       韧性：N/A
•       可服务：资源管理组件恢复后自动恢复列表过滤功能
•       可测试：N/A
•       支持的产品：A800

【部署类】支持一键部署与证书管理、可观测性

1. 简要说明

提供一键部署所有 IAM 组件的能力，支持 TLS 证书管理对接（含后量子密码算法预置能力），集成链路追踪可观测性。支持离线环境部署。

2. Actor

运维工程师：执行部署、升级、管理证书
运维工程师：查看链路追踪信息、排查问题

3. 前置条件

K8s 集群就绪，Gateway CRD 已安装

4. 最小保证

安装失败不影响已有集群资源
证书过期前有预警

5. 成功保证

1）一键部署所有 IAM 组件
2）Gateway HTTPS 监听正常
3）可查看请求链路追踪信息
4）版本更新不破坏现有数据
5）TLS 配置支持后量子密码算法（预置能力，可配置启用）

6. 触发事件

1）运维工程师：首次部署或版本升级
2）系统：证书即将过期触发续签
3）运维工程师：排查线上问题需查看链路信息

7. 主成功场景

一键部署：
1）运维工程师在全新环境执行部署命令，系统自动完成集群创建、镜像加载、全部 IAM 组件部署和初始化，运维工程师确认所有 Pod 正常运行
2）运维工程师在已有环境执行升级命令，系统滚动更新各组件，升级过程中业务请求不中断，运维工程师确认新版本部署成功且原有数据保留
3）运维工程师在无网络环境使用离线包执行部署，系统从离线包加载镜像和配置，完成与在线部署相同的全部初始化流程，运维工程师确认部署成功

证书管理：
1）运维工程师对接证书管理系统，系统自动为 Gateway 配置 HTTPS 监听证书，外部请求通过 HTTPS 加密访问，运维工程师确认 HTTPS 监听正常
2）证书即将过期时，证书管理系统自动完成续签和更新，Gateway 无缝切换到新证书，业务请求不中断
3）运维工程师根据安全要求启用后量子密码算法（如 ML-KEM/ML-DSA），系统切换 TLS 配置使用后量子算法进行密钥交换和签名，运维工程师确认 HTTPS 连接使用新算法

可观测性：
1）运维工程师排查线上问题时，通过链路追踪系统查看某个请求从 Gateway 到各后端服务的完整调用链路、耗时和状态，定位到问题所在的服务和环节

•       拒绝场景：N/A
•       约束：支持离线部署
•       规格：N/A
•       升级：支持滚动升级，不中断业务
•       可靠性：热路径组件 ≥2 副本
•       性能：N/A
•       安全：HTTPS 全链路加密，证书由证书管理系统管理，预置后量子密码算法能力

【IAM】支持 API Key 认证与管理

1. 简要说明

支持外部应用通过 API Key 访问知识库、记忆库等服务。API Key 认证后转换为等效的服务账号身份，进行路径鉴权和资源鉴权流程。提供 API Key 的完整生命周期管理（创建、查看、更新、删除、轮换）。

2. Actor

管理员：创建和管理 API Key
API Key 应用：携带 API Key 访问业务服务

3. 前置条件

资源实例创建完成

4. 最小保证

API Key 授权、鉴权操作对系统无影响

5. 成功保证

1）支持 API Key 创建、删除、一次性展示
2）支持应用通过 API Key 对资源鉴权
3）支持 API Key 轮换，不影响已有资源权限

6. 触发事件

1）管理员/用户：创建 API Key
2）管理员/用户：关联 API Key 与资源
3）外部应用：携带 API Key 进行资源请求访问
4）系统：根据 API Key 进行鉴权，并对请求进行放行或拒绝处理

7. 主成功场景

创建 Key：
1）管理员调用创建接口，指定应用名称、路径白名单和有效期，系统生成 API Key 并返回明文（仅此一次），管理员保存 Key 用于后续服务配置
2）管理员调用 Key 列表查询接口，系统返回该租户下所有 Key 的基本信息（前缀、应用名、状态、创建时间），不返回明文和哈希值

请求鉴权：
1）外部应用携带有效 API Key 请求访问业务路径，系统验证 Key 有效且路径在白名单内，将 Key 转换为等效服务账号身份后执行路径鉴权和资源鉴权，鉴权通过后请求到达后端应用
2）外部应用携带无效或已停用的 API Key 请求访问，系统返回 401 拒绝访问
3）外部应用携带有效 API Key 请求访问白名单外的路径，系统返回 403 拒绝访问
4）外部应用携带已过期的 API Key 请求访问，系统返回 401 拒绝访问

轮换 Key：
1）管理员调用轮换接口，系统生成新的 API Key 并替换旧 Key，保留原有服务账号身份（已授权的资源权限不受影响），返回新明文，管理员更新服务配置后旧 Key 立即失效

停用与删除：
1）管理员调用更新接口将 Key 设为停用，使用该 Key 的请求立即返回 401，管理员收到更新成功确认
2）管理员调用删除接口永久撤销 Key，该 Key 不可恢复，管理员收到删除成功确认

8. 扩展场景（包括异常场景）

•       拒绝场景：API Key 不存在返回 401、API Key 已停用返回 401、API Key 已过期返回 401、路径不在白名单返回 403
•       约束：N/A
•       规格：支持最大规格，见特性内部规格
•       升级：支持滚动升级，多副本逐个重启
•       可靠性：支持多副本部署
•       性能：N/A
•       安全：满足 API Key 安全规范要求，明文仅创建/轮换时一次性展示
•       韧性：N/A
•       可服务：支持操作日志记录
•       可测试：N/A
•       支持的产品：A800
