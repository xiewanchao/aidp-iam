aidp-iam business stack installed (v1.4 — merged 4-in-1 layout).

What was deployed:
  - Keycloak StatefulSet + PostgreSQL          -> keycloak
  - keycloak-init Job (writes aidp-client Secret cross-ns)  -> keycloak
  - iam-services Deployment (1 Pod, 2 containers)           -> aidp-iam
        container 1 [aidp-iam-app:v1]: keycloak-proxy + pep-proxy
                                       + bundle-server + resource-sync
                                       (under supervisord)
        container 2 [openpolicyagent/opa:0.70.0]: bare OPA on :8181
  - 5 Services (one per logical service, all pointing at the same Pod)  -> aidp-iam
  - HTTPRoutes (Keycloak public / Identity / ACL / path-rules)          -> envoy-gateway-system
  - SecurityPolicy pep-proxy-extauthz                                   -> envoy-gateway-system
  - 2 ReferenceGrants (gateway → keycloak ns, gateway → aidp-iam ns)

Mock test backends were NOT installed. Run separately:
  helm install aidp-mock-kb     ../mocks/package-mock-kb/charts/aidp-mock-kb         -n mock-kb     --create-namespace
  helm install aidp-mock-rubik  ../mocks/package-mock-rubik/charts/aidp-mock-rubik   -n mock-rubik  --create-namespace
  helm install aidp-mock-memory ../mocks/package-mock-memory/charts/aidp-mock-memory -n mock-memory --create-namespace

Verify Keycloak is reachable through the gateway:
  curl http://<EIP-or-node-ip>:30080/realms/aidp/.well-known/openid-configuration | head -c 200

Onboard a real business app (KB / Rubik / Memory / ...):
  See mocks/package-mock-kb/ for a full example: HTTPRoute + ReferenceGrant
  + SecurityPolicy + EnvoyExtensionPolicy. Each app brings its own four
  resources — they coexist with this release without patching.

Tear down:
  helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
  helm uninstall aidp-mock-kb -n mock-kb   # if installed
