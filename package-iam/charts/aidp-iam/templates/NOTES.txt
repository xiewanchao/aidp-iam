aidp-iam business stack installed.

What was deployed:
  - Keycloak StatefulSet + PostgreSQL          -> keycloak
  - keycloak-init Job                          -> keycloak
  - iam-services Deployment                    -> aidp-iam
  - IAM public/protected HTTPRoutes             -> envoy-gateway-system
  - SecurityPolicy pep-proxy-extauthz           -> envoy-gateway-system
  - ReferenceGrants for gateway cross-namespace backend access

Verify Keycloak through the gateway:
  curl http://<EIP-or-node-ip>:30080/realms/aidp/.well-known/openid-configuration | head -c 200

Verify an admin token:
  SECRET=$(kubectl -n aidp-iam get secret keycloak-aidp-client -o go-template='{{`{{`}}index .data "client-secret" | base64decode{{`}}`}}')
  curl -sS -X POST http://<EIP-or-node-ip>:30080/realms/aidp/protocol/openid-connect/token \
    -d "grant_type=password&client_id=aidp-client&client_secret=$SECRET&username=admin&password=Admin@123" \
    | python3 -c "import json,sys; print(json.load(sys.stdin)['access_token'][:50])"

CAS protocol is available when the bundled keycloak-custom:26.5.2 image is used:
  CAS base URL: http://<EIP-or-node-ip>:30080/realms/aidp/protocol/cas

Install the optional CAS client demo:
  kubectl apply -f tests/iam-auth/cas-client-demo.k8s.yaml
  kubectl -n aidp-iam port-forward svc/cas-client-demo 18080:18080

Tear down:
  helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
